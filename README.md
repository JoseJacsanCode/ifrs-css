# IFRS CSS

Repositório de estudos de **HTML e CSS** com exemplos práticos. Cada pasta reúne uma página independente que demonstra um conceito ou recurso de estilização, do básico (como aplicar CSS) até layouts com Flexbox e Grid.

## Conteúdos

Os exemplos estão organizados em seis grupos:

| Grupo | O que cobre |
| --- | --- |
| **Fundamentos** | Formas de aplicar CSS (inline, interno e externo), seletores e a regra `!important` |
| **Texto** | Alinhamento, decoração, transformação e espaçamento entre linhas |
| **Links, listas e formulários** | Estilização de links, listas e formulários |
| **Caixa e espaçamento** | Margens, preenchimentos, bordas e sombras |
| **Fundos e cores** | Fundos e efeitos de gradiente |
| **Layout e posicionamento** | Posicionamento de elementos, Flexbox e CSS Grid |

## Como visualizar

Não é preciso instalar dependências nem rodar um servidor. Basta clonar o repositório e abrir o arquivo HTML do exemplo desejado no navegador.

```bash
git clone https://github.com/JoseJacsanCode/ifrs-css.git
cd ifrs-css
```

Depois, entre na pasta do tema que quiser (por exemplo, `flexbox/` ou `grid-layout/`) e abra o arquivo HTML dela com um duplo clique ou pelo navegador.
