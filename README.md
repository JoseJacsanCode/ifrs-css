# IFRS CSS

Repositório de exemplos práticos de **HTML e CSS** para estudo. Cada pasta apresenta uma página independente que demonstra um conceito ou recurso de estilização.

## Conteúdos

Os exemplos cobrem, entre outros temas:

- formas de aplicar CSS: inline, interno e em arquivo externo;
- seletores CSS e a regra `!important`;
- cores de fundo, imagens, preenchimentos e margens;
- alinhamento e formatação de texto, incluindo decoração, transformação e espaçamento entre linhas;
- posicionamento de elementos com `position` e técnicas de layout;
- layouts com Flexbox e CSS Grid.

## Como visualizar

Não é necessário instalar dependências ou executar um servidor. Clone ou baixe o repositório e abra o `index.html` do exemplo desejado em um navegador.

```bash
git clone https://github.com/JoseJacsanCode/ifrs-css.git
cd ifrs-css
```

Em seguida, abra o arquivo `index.html` de uma das pastas de exemplo, por exemplo `flexbox/index.html` ou `grid-layout/index.html`.

## Organização

Cada diretório representa um tópico e, quando necessário, contém seus próprios arquivos HTML, CSS e recursos visuais. Alguns exemplos usam nomes de pastas em português e outros em inglês; consulte a lista de diretórios para encontrar o assunto desejado.

## Tecnologias

- HTML5
- CSS3
